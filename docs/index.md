# Welcome to the Neurological Disease Ontology

The Neurological Disease Ontology (ND) is a comprehensive ontology representing neurological diseases and related biomedical entities. It is developed using the [Ontology Development Kit (ODK)](https://github.com/INCATools/ontology-development-kit), which provides a standardized framework for ontology development.

## Quick Links

- **Browse the ontology**: [OLS Browser](http://www.ebi.ac.uk/ols/ontologies/nd)

- **Issue Tracker**: [Report issues or request terms](https://github.com/addiehl/neurological-disease-ontology/issues)

## Available Releases

The ontology is available in multiple formats and variants:

### Format Options
- **OWL** (.owl) - OWL 2 format for logic-based reasoning
- **OBO** (.obo) - OBO format for biomedical ontologies
- **JSON** (.json) - JSON format for programmatic access

### Release Variants
- **Full** (nd-full) - Complete ontology with all imports
- **Base** (nd-base) - Core ontology without import closure
- **Simple** (nd-simple) - Simplified version without complex axioms

Access all releases at: [purl.obolibrary.org/obo/nd](http://purl.obolibrary.org/obo/nd)

## Key Ontologies Integrated

The ND ontology incorporates terms from:
- **BFO** (Basic Formal Ontology)
- **OBI** (Ontology for Biomedical Investigations)
- **PR** (PRotein Ontology)
- **RO** (Relationship Ontology)
- **UBERON** (Anatomical entities)
- **OGMS** (Ontology of General Medical Science)
